# PyTorch CRNN — Training Results

Test-set performance of the PyTorch port compared to the original
TensorFlow/Keras model (`models/CRNN/best_model_V3.h5`).

Both models share the same architecture (Conv1D×3 → BiLSTM(256) → per-meter
sigmoid, masked binary cross-entropy) and the same meter-segmented,
NMF-decomposed feature pipeline. The PyTorch model was trained on the segments
regenerated by `scripts/preprocess.py` (331 songs, 70/15/15 split, seed 42).

| Metric | TensorFlow (baseline) | PyTorch port |
|---|---|---|
| Loss | 0.278 | 0.294 |
| Accuracy | 0.891 | 0.886 |
| Precision | 0.831 | 0.865 |
| Recall | 0.900 | 0.858 |
| F1 score | 0.864 | 0.862 |

Training: Adam (lr 1e-3), ReduceLROnPlateau, early stopping (stopped at epoch
24). Batch size 16 (fits an 8 GB GPU; the original used 32). GPU: NVIDIA
GTX 1070 Ti.

The F1 scores match within 0.002, confirming the port faithfully reproduces
the original model. The PyTorch model trades a little recall for higher
precision, but overall discrimination is equivalent.
